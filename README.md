# eth-rlp

RLP encoder/decoder for Ethereum node-discovery (discv4) UDP packets.

`Status: Utility` · `Python` · part of [TrustSentinel](https://trustsentinel.eu)

## Overview
A small, correct RLP (Recursive Length Prefix) codec for the packets exchanged
during Ethereum's discv4 node-discovery handshake — the kind of primitive the
scanners are built on.

## Usage
```bash
python sample.py
```
